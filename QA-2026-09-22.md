# Design controls QA - 2026-09-22

Implemented grouped typed controls (including bounded number sliders, boolean and font fields), browser-local reusable color/font styles, on-demand SVG background creation, case-study templates for statics and carousels, adaptive galleries, and configurable starter-headline timing. No new runtime dependency or external source code was imported. Personal studio.config.json changes were preserved.

## Verified

- Browser regression: editing does not request a preview; Save requests one preview; saved headline survives aspect-ratio navigation; saved visual style restores colors; generated SVG uploads successfully; invalid duration cannot be saved.
- Eighteen PNG exports: both case-study media categories, all three sizes, all three layout variants. Inspected square/editor and portrait-story output. Revised the gallery to choose columns using available width and height.
- MP4 with durationSeconds=6, entranceSeconds=1, exitSeconds=1: ffprobe reports 6.000000 seconds. Inspected the three-second frame; headline, second line and caption are present.
- Motion PNG regression: three identical hashes. Final HyperFrames check: no lint/runtime/motion errors or warnings, no layout issues across nine samples, all nine text contrast checks pass.
- Existing saved-edit, brand and setup tests pass. Build recovery regression passed twice after one transient Windows fixture failure. Rebuilding while the QA server was active also encountered a Windows rename failure; stopping that server allowed the build to complete. No build-lock redesign is claimed here.

## Boundaries

No screen-sharing/laptop performance benchmark, full 120-second render, or fresh-machine install was performed. No new transparent-MOV test was run in this pass. Artwork is original bundled SVG; the background creator is procedural, not an AI image API. Case-study slides are exported individually. Presets are browser-local. Other motion templates retain their own authored timing. The starter UI's 2-120-second bounds are not a HyperFrames engine limit.

## Reproduce

Start the server on an unused port, then set STUDIO_URL to its URL and run node tests/design-controls-regression.mjs and node tests/motion-png-regression.mjs. Run node tests/editor-save-regression.mjs, node tests/brand-regression.mjs, node tests/setup-regression.mjs, and node tests/build-regression.mjs separately.
